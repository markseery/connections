## Products

**Cloud Compute Products:**

1. **Superclusters** — Single-tenant, shared-nothing AI supercomputers. 4,000 to 165,000+ NVIDIA GPUs. Contract terms 3-5 years. Support NVIDIA GB300 NVL72 and HGX B300 systems. Purpose-built for mission-critical large-scale training and inference. Feature: enterprise-grade security, caged clusters, hardware-level isolation, NVIDIA Quantum-2/Quantum-X800 InfiniBand. Liquid-cooled, high-density.

2. **1-Click Clusters™** — Self-serve, production-ready GPU clusters. 16 to 2,000+ NVIDIA GPUs (HGX B200 and H100). Commitment: 2 weeks to 3 years. Connected with NVIDIA Quantum-2 InfiniBand (3.2 Tb/s aggregate). Pricing: NVIDIA HGX B200 on-demand $4.62/GPU/hr; NVIDIA H100 on-demand $2.76/GPU/hr. Reserved pricing available for 1-3 year terms. Features: managed Kubernetes or Slurm orchestration, S3-compatible storage, SOC 2 Type II certified.

3. **Instances (On-Demand Cloud)** — 1 to 8 NVIDIA GPU virtual machines. Pay-by-the-minute. Available GPUs: NVIDIA B200 SXM6 (180 GB VRAM), GH200 (96 GB), H100 SXM (80 GB), H100 PCIe (80 GB), A100 SXM (80 GB & 40 GB), A100 PCIe (40 GB), A10 (24 GB), A6000 (48 GB), Quadro RTX 6000 (24 GB), Tesla V100 (16 GB). Pricing ranges from $0.58/GPU/hr (RTX 6000) to $6.08/GPU/hr (1x B200). Pre-installed with Lambda Stack (PyTorch, TensorFlow, CUDA, cuDNN, etc.).

4. **Inference API** — Serverless API for open-source models (winding down per website). No rate limits. Models hosted include DeepSeek-R1-0528, DeepSeek V3-0324, Qwen3-32B, and others. OpenAI-compatible API.

5. **Lambda Chat** — Chat interface for interacting with hosted open-source models (e.g., DeepSeek-R1).

**Software Products:**

6. **Lambda Stack** — Free Ubuntu APT package/deep learning software suite. Pre-installed on all Lambda products. Includes: PyTorch 2.7.0, TensorFlow 2.19.0, Keras 3.10.0, JAX 0.6.0, CUDA 12.8.93, cuDNN, NCCL 2.26.2, NVIDIA Container Toolkit. Over 100,000 users. Available for non-Lambda systems via install script.

7. **Filesystem S3 Adapter** — S3-compatible API for Lambda's persistent storage. Supports GetObject, PutObject, DeleteObject, list operations. Available in US-East-2 and US-East-3.

8. **Cloud Metrics Dashboard** — Real-time GPU and system monitoring. Powered by lambda-guest-agent. Metrics include GPU utilization, VRAM utilization, CPU utilization, memory utilization, Ethernet bandwidth, InfiniBand bandwidth.
