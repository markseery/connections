<h2 style="margin:0 0 20px;font-size:22px;font-weight:700;color:#111111;letter-spacing:-0.3px;">AI Agents &amp; Creative Tools</h2>
<p style="margin:0 0 16px;font-size:15px;line-height:1.7;color:#333333;">
<strong>Canva</strong> <a href="https://techcrunch.com/2026/04/16/canvas-ai-assistant-can-now-call-various-tools-to-make-designs-for-you/" style="color:#2563eb;text-decoration:none;">updated its AI assistant</a> to plan and execute design tasks using tool-calling, creating editable layered designs from text prompts. This mirrors moves by <strong>Adobe</strong>, which launched its <strong>Firefly AI Assistant</strong> (public beta), capable of <a href="https://techcrunch.com/2026/04/15/adobes-new-firefly-ai-assistant-can-use-creative-cloud-apps-to-complete-tasks/" style="color:#2563eb;text-decoration:none;">orchestrating tasks across Photoshop, Premiere, Illustrator, and other Creative Cloud apps</a>. <strong>Figma</strong> recently added MCP server support for AI agents.
</p>
<p style="margin:0 0 16px;font-size:15px;line-height:1.7;color:#333333;">
<strong>OpenAI</strong> <a href="https://techcrunch.com/2026/04/15/openai-updates-its-agents-sdk-to-help-enterprises-build-safer-more-capable-agents/" style="color:#2563eb;text-decoration:none;">updated its Agents SDK</a> with sandboxing, in-distribution harness for frontier models, and compatibility with sandbox providers to help enterprises build safer, long-horizon agents.
</p>
<p style="margin:0 0 16px;font-size:15px;line-height:1.7;color:#333333;">
Indian startup <strong>Emergent</strong> (backed by <strong>SoftBank</strong>, Khosla, Lightspeed; $70M raise at $300M valuation) <a href="https://techcrunch.com/2026/04/15/indias-vibe-coding-startup-emergent-enters-openclaw-like-ai-agent-space/" style="color:#2563eb;text-decoration:none;">launched <strong>Wingman</strong></a>, an autonomous AI agent operating via WhatsApp/Telegram, competing with tools like OpenClaw and <strong>Anthropic's</strong> Claude agents. <strong>Microsoft</strong>-owned <strong>LinkedIn</strong> is also exploring agent-adjacent AI integrations.
</p>

<strong>Allbirds</strong> (Nasdaq: BIRD), <a href="https://techcrunch.com/2026/04/15/after-sale-of-its-shoe-business-allbirds-pivots-to-ai/" style="color:#2563eb;text-decoration:none;">after selling its shoe brand for $39M</a>, rebranded as <strong>NewBird AI</strong>, a "GPU-as-a-Service and AI-native cloud solutions provider," securing $50M in convertible financing to acquire GPU assets—<a href="https://www.ft.com/content/a4b63cc1-2d1c-44c8-a22a-425cf0efb5cf" style="color:#2563eb;text-decoration:none;">drawing comparisons to Long Island Iced Tea's blockchain pivot</a>.
</p>
<p style="margin:0 0 16px;font-size:15px;line-height:1.7;color:#333333;">
<strong>Parasail</strong> raised a <strong>$32M Series A</strong> to provide <a href="https://techcrunch.com/2026/04/15/parasail-raises-32m-to-feed-tokenmaxxing-ai-developers/" style="color:#2563eb;text-decoration:none;">cloud inference services</a>, generating 500 billion tokens/day by orchestrating workloads across 40 data centers in 15 countries, competing with proprietary chip owners.
</p>
<p style="margin:0 0 16px;font-size:15px;line-height:1.7;color:#333333;">

<td style="padding:0 48px;">
<p style="margin:0 0 8px;font-size:11px;font-weight:700;text-transform:uppercase;letter-spacing:1.5px;color:#6b6b6b;">03</p>
<h2 style="margin:0 0 20px;font-size:22px;font-weight:700;color:#111111;letter-spacing:-0.3px;">Anthropic vs. OpenAI Rivalry</h2>
<p style="margin:0 0 16px;font-size:15px;line-height:1.7;color:#333333;">
<strong>Anthropic's</strong> annualized revenue surged from $9B (end of 2025) to <strong>$30B by March 2026</strong>, largely from coding tools, making its $380B valuation look attractive relative to <strong>OpenAI's</strong> $852B. Some <a href="https://www.ft.com/content/04ac7917-940b-4606-be5f-9eb895a7d982" style="color:#2563eb;text-decoration:none;">OpenAI investors are expressing doubt</a>, with <a href="https://techcrunch.com/2026/04/14/anthropics-rise-is-giving-some-openai-investors-second-thoughts/" style="color:#2563eb;text-decoration:none;">secondary-market demand for Anthropic shares far outstripping OpenAI's</a>. <a href="https://www.ft.com/content/abb93a6f-9060-4095-8045-84b97d394a4c" style="color:#2563eb;text-decoration:none;">Anthropic is closing in on OpenAI as US business use surges</a>.
</p>
<p style="margin:0 0 16px;font-size:15px;line-height:1.7;color:#333333;">
Anthropic co-founder <strong>Jack Clark</strong> <a href="https://techcrunch.com/2026/04/14/anthropic-co-founder-confirms-the-company-briefed-the-trump-administration-on-mythos/" style="color:#2563eb;text-decoration:none;">confirmed briefing the Trump administration</a> on its new <strong>Mythos</strong> model—deemed too dangerous for public release due to <a href="https://www.ft.com/content/4334460f-b599-4578-8840-d1c7ecf01e08" style="color:#2563eb;text-decoration:none;">cybersecurity capabilities</a>—while simultaneously suing Trump's DOD over a supply-chain risk designation tied to disputes over military AI use (mass surveillance, autonomous weapons). <a href="https://www.ft.com/content/ec7bb366-9643-47ce-9909-fc5ad4864ae5" style="color:#2563eb;text-decoration:none;"><strong>UK financial regulators</strong> are rushing to assess Mythos risks</a>. <strong>OpenAI</strong> <a href="https://www.ft.com/content/cf3d62e0-1b6c-4e69-b5f7-facaca586dbf" style="color:#2563eb;text-decoration:none;">released a new cybersecurity model to a limited customer group</a>.
</p>
